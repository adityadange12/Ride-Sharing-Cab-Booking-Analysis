# Ride Sharing & Cab Booking Analysis

## Project Overview
This project focuses on analyzing ride-sharing and cab booking data to understand booking trends, revenue, driver performance, customer ratings, trip distances, and fares.

The main objective is to extract meaningful insights from the data and support better business decision-making.

## Project Objectives
- Analyze total rides and revenue.
- Identify peak booking hours.
- Evaluate driver performance and ratings.
- Analyze customer ratings and satisfaction.
- Understand trip distance and fare patterns.
- Identify pickup locations with higher booking activity.
- Build an interactive Power BI dashboard.

## Tools & Technologies Used
- **SQL:** Data querying and analysis.
- **Python:** Data analysis and exploration.
- **Pandas:** Data cleaning and manipulation.
- **NumPy:** Numerical operations.
- **Matplotlib & Seaborn:** Data visualization.
- **Power BI:** Interactive dashboard development.
- **Jupyter Notebook:** Python development environment.

## Datasets
The project uses five datasets:

1. Users
2. Drivers
3. Vehicles
4. Rides
5. Ratings

The datasets were cleaned and prepared for analysis.

## Project Analysis

### SQL Analysis
- Total rides and revenue.
- Average trip distance and fare.
- Peak booking hours.
- Driver ratings.
- Top-performing drivers.

### Python Analysis
- Data loading and exploration.
- Missing value handling.
- Duplicate checking.
- Statistical analysis.
- Booking trends and driver performance.
- Data visualization.

### Power BI Dashboard
An interactive dashboard was developed to present key performance indicators and visual insights, including monthly ride trends, hourly ride analysis, driver performance, customer ratings, pickup locations, and fare versus distance.

## Key Findings
- Total Rides: 50,000
- Total Revenue: 2,871,581.19
- Total Users: 10,000
- Total Drivers: 300
- Average Fare: 57.43
- Average Trip Distance: 25.54 km
- Average Customer Rating: 3.01 / 5
- Average Ride Duration: 62.46 minutes

## Project Limitations
The available dataset does not contain ride status/cancellation and payment method information. Therefore, cancellation rate and payment method distribution could not be analyzed.

## Conclusion
This project provided practical experience in SQL, Python, data cleaning, exploratory data analysis, data visualization, and Power BI dashboard development. The analysis helped identify important patterns and business insights from ride-sharing data.
